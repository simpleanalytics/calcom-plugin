# Simple Analytics app for the Cal.diy App Store: evidence

Screenshots and listing image options for the pull request that adds the Simple Analytics app
(`packages/app-store/simple-analytics` on the `feat/simple-analytics` branch).

- `pr/`: screenshots from a local Cal.diy instance (listing page and event type settings, dark and light).
- `image-options/`: six candidates for the listing image, 1600 x 1280 px each, three per model.
  `all-six-in-listing.png` shows them inside the real listing page.
- `image-options/source/`: the HTML each image was rendered from. To re-render one, copy the Space Grotesk
  `.woff2` files from `marketing-site/public/fonts/space-grotesk` into `image-options/source/assets/fonts/`
  and open the file in a browser at 1600 x 1280.

The app ships `image-options/fable-1.png` as `static/1.png`.
